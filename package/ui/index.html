Collector task (one-time setup)

  1. Open Control Panel › Task Scheduler › Create › Scheduled Task › User-defined script.
  2. General: name it SecDash collector and set User to root.
  3. Schedule: daily, repeat every 5 minutes all day.
  4. Task Settings: paste the script below into Run command, then save and click Run once.

The script only copies DSM's block list and logs into SecDash's inbox. It is extracted as the unprivileged sc-secdash user and never runs code from the package.
